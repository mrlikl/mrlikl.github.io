# Security policy

## Reporting a vulnerability

Please report security problems privately, not in a public issue.

Use GitHub's private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability** (https://github.com/mrlikl/mrlikl.github.io/security/advisories/new). The report is visible only to the maintainer.

Include what you found, how to reproduce it, and the version or commit affected. You can expect a first reply within a week.

## Supported versions

Only the site as currently deployed from `main` is supported.
